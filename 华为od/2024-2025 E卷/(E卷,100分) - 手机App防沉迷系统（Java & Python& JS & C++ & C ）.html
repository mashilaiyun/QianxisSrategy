最新华为OD机试

题目描述

智能手机方便了我们生活的同时，也侵占了我们不少的时间。“手机App防沉迷系统”能够让我们每天合理地规划手机App使用时间，在正确的时间做正确的事。

它的大概原理是这样的：

  1. 在一天24小时内，可以注册每个App的允许使用时段
  2. 一个时间段只能使用一个App
  3. App有优先级，数值越高，优先级越高。注册使用时段时，如果高优先级的App时间和低优先级的时段有冲突，则系统会自动注销低优先级的时段，如果App的优先级相同，则后添加的App不能注册。

请编程实现，根据输入数据注册App，并根据输入的时间点，返回时间点使用的App名称，如果该时间点没有注册任何App，请返回字符串“NA”。

输入描述

第一行表示注册的App数量 N（N ≤ 100）

第二部分包括 N 行，每行表示一条App注册数据

最后一行输入一个时间点，程序即返回该时间点使用的App

2
App1 1 09:00 10:00
App2 2 11:00 11:30
09:30

数据说明如下：

  1. N行注册数据以空格分隔，四项数依次表示：App名称、优先级、起始时间、结束时间
  2. 优先级1~5，数字越大，优先级越高
  3. 时间格式 HH:MM，小时和分钟都是两位，不足两位前面补0
  4. 起始时间需小于结束时间，否则注册不上
  5. 注册信息中的时间段包含起始时间点，不包含结束时间点

输出描述

输出一个字符串，表示App名称，或NA表示空闲时间

示例1

输入

xxxxxxxxxx
1
App1 1 09:00 10:00
09:30

输出

xxxxxxxxxx
App1

说明

App1注册在9点到10点间，9点半可用的应用名是App1

示例2

输入

xxxxxxxxxx
2
App1 1 09:00 10:00
App2 2 09:10 09:30
09:20

输出

xxxxxxxxxx
App2

说明

APP1和App2的时段有冲突，App2优先级高，注册App2之后，App1自动注销，因此输出App2。

示例3

输入

xxxxxxxxxx
2
App1 1 09:00 10:00
App2 2 09:10 09:30
09:50

输出

xxxxxxxxxx
NA

// 时间转换函数，将时间字符串转换为以分钟为单位的整数
int convertTime(const std::string& time) {
    int hours, minutes;
    char colon;
    std::istringstream iss(time);
    iss >> hours >> colon >> minutes; // 将时间字符串按照":"分割并转换为小时和分钟
    return hours * 60 + minutes; // 将小时和分钟转换为分钟
}

        std::string startTimeStr, endTimeStr;
        std::cin >> appName >> appPriority >> startTimeStr >> endTimeStr;

    }

// 定义App结构体，用于存储App的相关信息
type App struct {
    name      string // App名称
    priority  int    // App优先级
    startTime int    // App允许使用的起始时间（以分钟为单位）
    endTime   int    // App允许使用的结束时间（以分钟为单位）
}
​
// 时间转换函数，将时间字符串转换为以分钟为单位的整数
func convertTime(timeStr string) int {
    parts := strings.Split(timeStr, ":")
    hours, _ := strconv.Atoi(parts[0])
    minutes, _ := strconv.Atoi(parts[1])
    return hours*60 + minutes
}
​
func main() {
    scanner := bufio.NewScanner(os.Stdin)
    scanner.Scan()
    n, _ := strconv.Atoi(scanner.Text()) // 读取App数量
​
    apps := []App{} // 创建App列表，用于存储所有App
    for i := 0; i < n; i++ {
        scanner.Scan()
        line := scanner.Text()
        parts := strings.Split(line, " ")
        appName := parts[0]
        appPriority, _ := strconv.Atoi(parts[1])
        startTimeStr := parts[2]
        endTimeStr := parts[3]
        appStartTime := convertTime(startTimeStr)
        appEndTime := convertTime(endTimeStr)
        apps = append(apps, App{name: appName, priority: appPriority, startTime: appStartTime, endTime: appEndTime})
    }
​
    scanner.Scan()
    queryTimeStr := scanner.Text()
    queryTime := convertTime(queryTimeStr) // 读取查询时间，并转换为分钟
    appAtTime := "NA" // 初始化查询时间对应的App名称为"NA"
​
    registeredApps := []App{} // 创建已注册App列表
    for _, app := range apps {
        if app.startTime >= app.endTime {
            continue // 如果起始时间不小于结束时间，则跳过
        }
        canInsert := true
        needDeletePositions := []int{}
        // 遍历已注册的App列表，检查时间冲突
        for i := len(registeredApps) - 1; i >= 0; i-- {
            registered := registeredApps[i]
            if max(app.startTime, registered.startTime) < min(app.endTime, registered.endTime) {
                if app.priority > registered.priority {
                    needDeletePositions = append(needDeletePositions, i) // 记录需要移除的位置
                } else {
                    canInsert = false // 当前App优先级不够高，无法插入
                }
            }
        }
        if canInsert {
            registeredApps = append(registeredApps, app) // 插入当前App
            for _, pos := range needDeletePositions {
                registeredApps = append(registeredApps[:pos], registeredApps[pos+1:]...) // 移除冲突的App
            }
        }
    }
​
    // 遍历已注册App列表，找到查询时间对应的App
    for _, app := range registeredApps {
        if queryTime >= app.startTime && queryTime < app.endTime {
            appAtTime = app.name // 更新查询时间对应的App名称
            break // 找到后退出循环
        }
    }
​
    fmt.Println(appAtTime) // 输出查询时间对应的App名称
}

// 辅助函数：反转整数切片
func reverse(slice []int) []int {
    for i, j := 0, len(slice)-1; i < j; i, j = i+1, j-1 {
        slice[i], slice[j] = slice[j], slice[i]
    }
    return slice
